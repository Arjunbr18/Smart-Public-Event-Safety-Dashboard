# Smart Public Event Safety Dashboard

## Project Overview

Large public gatherings such as sports celebrations, concerts, festivals, and political rallies attract thousands or even lakhs of people. While these events create excitement and community engagement, they also present significant challenges related to crowd control, safety management, and emergency response.

In recent times, several real-world incidents have highlighted the importance of effective crowd monitoring. For example, the **RCB celebration stampede incident in Bengaluru** showed how quickly crowd situations can become dangerous when the number of people exceeds the safe capacity of a venue. Similarly, large political gatherings such as **Vijay's political rally in Tamil Nadu** demonstrated how massive crowds require careful planning, monitoring, and security coordination to avoid accidents or public safety risks.

These events inspired the idea behind this project.

This project presents a **Power BI dashboard designed to analyze and monitor crowd safety during large public events**. The dashboard uses data visualization techniques to track crowd distribution, incident reports, police deployment, and environmental conditions that may influence crowd behaviour.

The goal of the project is to show how **data analytics can support smarter decision-making for event organizers, law enforcement, and safety authorities**.

---

## Problem Statement

Managing large crowds during public events is complex and unpredictable. Event organizers and security teams often need to answer critical questions such as:

- Which zones of the venue are becoming overcrowded?
- Are medical incidents increasing as the crowd grows?
- Is the number of security personnel sufficient for the crowd size?
- Are environmental factors such as weather or temperature affecting the crowd?

Without proper monitoring systems, identifying risks early becomes difficult. Delayed decisions in such situations can lead to accidents, panic, or crowd stampedes.

This project attempts to address this challenge by building an **interactive Power BI dashboard that visually analyzes crowd safety data in real time**.

---

## Solution

The solution is a **multi-page Power BI dashboard** that helps visualize and analyze different aspects of event safety.

The dashboard combines multiple parameters such as:

- Crowd count
- Entry and exit flow
- Medical incidents
- Security alerts
- Police deployment
- Weather and temperature conditions

Through interactive charts and filters, the dashboard allows users to quickly identify potential risk zones and understand how crowd behaviour changes over time.

## Dataset Description

The dataset used in this project represents simulated monitoring data from public events.

| Column | Description |
|------|-------------|
| Event_ID | Unique identifier for the event |
| Event_Name | Name of the public event |
| Date / Time | Timestamp of the recorded observation |
| Zone | Specific area within the event venue |
| Crowd_Count | Number of people present in the zone |
| Entry_Count | Number of people entering the zone |
| Exit_Count | Number of people leaving the zone |
| Medical_Incidents | Number of medical emergencies reported |
| Security_Alerts | Number of security alerts detected |
| Police_Deployed | Number of police officers deployed |
| Weather | Weather conditions during the event |
| Temperature | Environmental temperature |

## Key Insights

- Certain events attract significantly larger crowds.
- Some zones within venues experience higher congestion levels.
- Medical incidents and security alerts may increase as crowd density grows.
- Police deployment needs to be aligned with crowd distribution.
- Environmental conditions such as weather and temperature may influence crowd behaviour.
